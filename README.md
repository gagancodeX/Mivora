# Mivora ✦

A calm collection of tiny browser games designed for quiet moments.

## Games
- **Bubble Drift** — pop floating bubbles
- **Slow Breath** — follow a gentle breathing rhythm
- **Soft Match** — relaxed memory matching
- **Color Flow** — follow a color sequence

## Stack
HTML · CSS · JavaScript

No build step, dependencies, accounts, or backend required.

## Run
Open `index.html` in a browser, or deploy the repository as a static site.
